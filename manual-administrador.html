01

Introducción

Este manual describe las funciones de administración identificadas en la interfaz proporcionada del sistema USO Laboratorios. Está orientado al usuario con rol Administrador y explica la navegación, el acceso al módulo de espacios y el registro o actualización de su información.

Importante: las instrucciones de este documento se basan en las funcionalidades visibles en los componentes proporcionados. Las funciones que no aparecen en dichos componentes no se describen como disponibles.
02

Acceso al panel administrativo.

◷

Barra superior

La barra superior muestra el título correspondiente a la sección actual y el nombre del usuario autenticado. También incluye el avatar del usuario, un menú para cerrar sesión y el botón de notificaciones.

2 Seleccione una opción del menú para entrar al módulo correspondiente.

03

Gestión de espacios

El módulo Espacio permite registrar y modificar la información de los espacios administrados por la institución. El formulario permite definir sus datos generales, modalidad de reserva, capacidad, estado, permisos de visibilidad, estaciones de trabajo y coordinador.

Agregar un espacio

Para registrar un nuevo espacio:

1

Ingrese al módulo Espacio desde el menú lateral.

2

Seleccione la opción para agregar un espacio.

3

Complete la información general solicitada.

4

Configure el modo de reserva y las opciones correspondientes.

5

Seleccione el estado y los permisos de visibilidad.

6

Revise la información y presione Guardar.

Información general

Campo Descripción Obligatorio
Nombre espacio Nombre con el que se identificará el espacio. Sí
Modo de reserva Define si la reserva se realiza por espacio completo o por estación de trabajo. Sí
Edificio Edificio donde se encuentra ubicado el espacio. Sí
Piso Piso en el que se encuentra el espacio. Sí
Aula / número Identificador o número del aula. Sí
Descripción Información adicional sobre el espacio. No
Validación: el sistema no permite guardar el espacio si faltan Nombre, Edificio, Piso o Aula. Si el modo es “Por Estación de Trabajo”, al crear un espacio también debe existir al menos una estación.
04

Modo de reserva

OPCIÓN 1

Espacio Completo

El espacio se configura como una unidad completa para la reserva. En esta modalidad se solicita la capacidad máxima de estudiantes.

OPCIÓN 2

Por Estación de Trabajo

El espacio se configura mediante estaciones de trabajo. Al crear el espacio, el administrador debe agregar al menos una estación.

Capacidad del espacio completo

Cuando se selecciona Espacio Completo, aparece el control Capacidad máxima de estudiantes. La capacidad puede incrementarse o reducirse mediante los botones de control o escribiendo directamente el valor.

Configuración de estaciones

En el modo Por Estación de Trabajo, se pueden agregar estaciones indicando:

  • Nombre o prefijo de la estación.
  • Cantidad de estaciones a crear.
  • Capacidad de cada estación.
EJEMPLO

Si se utiliza el prefijo PC y una cantidad de 3, el sistema genera una vista previa con nombres consecutivos como PC 1, PC 2 y PC 3.

Las estaciones agregadas aparecen en una lista con su nombre y capacidad. Cada estación puede quitarse antes de guardar utilizando el botón de eliminación.

Nota: al editar un espacio existente, el selector de modo de reserva aparece deshabilitado. Por ello, el modo configurado no puede cambiarse desde este formulario.
05

Asignación de coordinador

Para el usuario con rol Administrador, el formulario incluye la opción Asignar coordinador (opcional).

1

Ubique el campo Buscar coordinador....

2

Escriba el nombre del coordinador que desea buscar.

3

Seleccione al coordinador de la lista de resultados.

4

Si no desea asignar uno, seleccione Ninguno.

La lista se filtra utilizando el nombre y apellido de los usuarios cuyo rol es coordinador.

06

Estado del espacio

El administrador puede seleccionar uno de los siguientes estados:

DISPONIBLE Listo para usar
EN MANTENIMIENTO En reparación
CLAUSURADO Fuera de servicio

Seleccione la tarjeta correspondiente al estado que desea asignar al espacio antes de guardar.

07

Permisos de visibilidad

El formulario permite definir qué roles pueden visualizar el espacio. Las opciones disponibles son:

Todos Estudiante Docente Coordinador Supervisor

Las opciones seleccionadas se muestran visualmente diferenciadas. Puede seleccionar Todos o elegir roles específicos.

Recomendación: revise los permisos de visibilidad antes de guardar, especialmente cuando un espacio deba estar disponible solamente para determinados roles.
08

Editar un espacio

Cuando se abre un espacio existente para edición, el formulario carga sus datos actuales: nombre, descripción, ubicación, estado, modo de reserva, capacidad, coordinador y permisos de visibilidad.

1

Abra el espacio que desea modificar.

2

Actualice los campos permitidos.

3

Presione Guardar.

4

El sistema muestra una ventana de confirmación con el mensaje “¿Estás seguro que deseas actualizar esta información?”.

5

Seleccione Actualizar para confirmar o Cancelar para regresar al formulario.

Importante: durante la edición, el modo de reserva permanece deshabilitado y las estaciones no se agregan mediante este formulario de edición.
09

Guardar y cancelar

Guardar

Registra el nuevo espacio o guarda las modificaciones realizadas.

Cancelar

Cierra el formulario sin continuar con la operación.

Mientras se procesa el guardado, el botón cambia a “Guardando...” y las acciones de cierre permanecen deshabilitadas mientras corresponde.

10

Mensajes y confirmaciones

Confirmación de actualización

Al modificar un espacio, el sistema solicita confirmación antes de aplicar los cambios. La ventana presenta los botones Actualizar y Cancelar.

Errores del formulario

Si no se completan los campos obligatorios, el sistema muestra un mensaje indicando qué información debe completarse. Si el modo por estación no tiene estaciones al crear el espacio, también se muestra una advertencia.

Cierre de ventanas

Las ventanas de confirmación pueden cancelarse mediante su acción de cancelar. La interfaz también incorpora comportamiento de cierre mediante la tecla Escape en el componente de confirmación.

11

Cierre de sesión

Para finalizar la sesión, haga clic sobre el avatar situado en la parte superior derecha. Se desplegará la opción Cerrar sesión. Selecciónela para salir de la cuenta.

1 Haga clic en el avatar.
2 Seleccione “Cerrar sesión”.
12

Referencia rápida del administrador

Necesidad Acción
